### 🔹Сервис перевода денег

Full-stack приложение для перевода денег с одной банковской карты на другую.

Проект состоит из двух частей:

- REST API на Spring Boot
- готового frontend-приложения

## Backend

REST-сервис, реализующий операции перевода денег между картами.

**Технологии:**

`Java` `Spring Boot` `REST API` `Maven` `Docker` `Docker Compose` `JUnit` `Mockito` `Testcontainers`

👉 [Репозиторий](https://github.com/klimp2287/netology-transfer-money)

## Frontend

Веб-интерфейс для выполнения переводов с карты на карту.

**Технологии:**

`TypeScript` `React` `HTML` `CSS` `npm`

👉 [Репозиторий](https://github.com/klimp2287/netology-transfer-money-front)
